# 🐧 Linux Security Checklist

A beginner-friendly interactive checklist for learning basic Linux security concepts.

## 🚀 Features

- ☑️ Interactive security checklist
- 📊 Real-time progress percentage
- 🟢 Visual progress bar
- 💾 Progress saved using browser localStorage
- 🔄 Reset progress button
- 📚 Short explanations for each topic
- 🌙 Linux/Cybersecurity themed interface
- 🌐 Deployed with GitHub Pages

## 📚 Topics Covered

- Linux Users & Groups
- File Permissions
- sudo
- Basic Linux Commands
- Processes
- SSH Basics

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Git & GitHub
- GitHub Pages
- Browser localStorage

## 🎯 Purpose

This project was created as a beginner cybersecurity learning project.

It helps practice basic Linux security concepts while also learning how to build an interactive web application.

## 🔐 Security Focus

The project introduces important Linux security foundations such as:

- Access control
- File permissions
- User privileges
- Processes
- Secure remote administration

## 🌍 Live Demo

The project is deployed using GitHub Pages.

## 📌 Disclaimer

This project is educational and does not perform security testing or attacks against systems.
