🐧 Linux Security Checklist

A beginner-friendly checklist for learning basic Linux security concepts.

Learn how Linux organizes users and groups and how permissions are assigned.

Learn how Linux uses read, write, and execute permissions to control access to files and directories.

Learn how sudo allows authorized users to run commands with elevated privileges.

Learn essential commands for navigating files, directories, processes, and system information.

Learn what processes are, how they run, and how to monitor them in Linux.

Learn the basics of Secure Shell (SSH), including its purpose and secure remote administration.
